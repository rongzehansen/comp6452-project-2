Project 2 – Blockchain-Based Application Design and Development

| How to run the frontend     |
| :-------------------------- |
| Go to frontend folder       |
| "npm install"               |
| "npm start"                 |
| go to http://localhost:3000 |
|                             |

| How to run backend                                                                                |
| :------------------------------------------------------------------------------------------------ |
| go to backend folder                                                                              |
| If prisma/dev.db does not exists, run to create dev.db<br /> "npx prisma migrate dev --name init" |
| "npm run dev"                                                                                     |
| go to http://localhost:5000                                                                       |
| This is API server. Don't need to access directly through the web browser                        |
|                                                                                                   |
